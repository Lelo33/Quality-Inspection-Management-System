# Labs

Short Python exercises built around the Quality Inspection Management System.
Each lab is one file with instructions, starter code, a reference solution and
self-checks. Open a file, complete the TODO functions, then run it. When every
check says OK, you are done.

| Lab | Topic | Skills |
|-----|-------|--------|
| `lab1_pass_rate.py` | Pass rate and failed inspection positions | loops, lists, conditionals |
| `lab2_run_rule.py` | SPC run rule: 7 points on one side of the mean | algorithm design, edge cases |
| `lab3_rank_lines.py` | Rank production lines by defect rate | dictionaries, sorting |

## How to run a lab
1. Make sure you have Python installed
2. Open your terminal in the project folder
3. Run: `python labs/lab1_pass_rate.py`
4. Complete the TODO functions and run it again
